# evidence 轴（证据强度）落地报告（2026-11-02 · A8 方案 A）

> 背景：A8 的原始设想是「ingest 按证据推断 **grade**」。动手前先做离线评估 ⇒ **该方案被实测否决**，
> 改为**新增正交字段 `evidence`**（不动 `grade`、不动存量卡）。

## 一、为什么不能用关键词推断 `grade`（否决依据）

| 指标 | 实测 |
| -- | -- |
| 规则有强信号表态 | 23 / 616（4%） |
| **与人工标注一致率** | **22%（5/23）** |
| 反向误杀 | 有（人工 `proven` → 规则 `pitfall`） |

**根因**：`grade` 是**混合轴** —— 强制性（iron）× 证据强度（proven/task）× 体裁（pitfall/domain）。
三个正交维度被压进一个标签，关键词只能拟合其中一维 ⇒ 低一致率是**结构性的**，不是规则不够好。

⇒ 结论：**不改 `grade`**（存量 616 张的人工标注不因机械规则被推翻）。

## 二、改为正交轴 `evidence`（none / measured / t1）

| 取值 | 含义 |
| -- | -- |
| `t1` | 本卡做过 **T1 亲跑**验证（frontmatter 显式声明 / T1 小节且节内有实质证据 / 出现沙盒路径） |
| `measured` | 本卡有**自证型**验证记录（测试通过数 / exit 码 / 负样本打红 / 实测次数 / 跑通时间 / 复现成功） |
| `none` | 没有可识别的自证记录（**默认**） |

**与 `grade` 正交**（实测交叉表）：

| grade \ evidence | t1 | measured | none |
| -- | -- | -- | -- |
| iron | 1 | 0 | 6 |
| proven | 35 | 15 | 86 |
| domain | 36 | 24 | 131 |
| pitfall | 2 | 5 | 33 |
| task | 3 | 27 | 212 |

⇒ 无相关（`proven` 与 `domain` 的证据分布几乎一样；`task` 里也有 27 张带 measured）⇒ **确实是一维新信息**。

## 三、规则的**三版迭代**（关键：每版都被实测打回）

| 版本 | 判据 | 实测问题 |
| -- | -- | -- |
| **v1** | 散文关键词（`已验证`/`静默失败`/`跑通`…） | 大量**误判**：引用别人的结论（「中枢现有向量链路已验证」）、规则陈述（「写完**必须**跑通再交付」） |
| **v2** | 只认**结构标记**（小节标题 + 结果形态） | 仍把「## 关键教训（适用所有 T1+ 任务）」这种**提及**误判成 T1 验证记录 |
| **v3（落地）** | T1 小节**且节内有实质证据**（结果形态/沙盒痕迹）；散文字号一律不算 | 抽样目视 **12/12 成立**（t1 与 measured 各 12） |

**v3 的三条硬约束**：
1. **只认结构**：小节标题 + 结果形态（`298/298 tests pass` / `exit 0` / `负样本…打红` / `实测 N 次` / `跑通时间` / `复现成功`）。
2. **排除要求语气**：「必须/应当/禁止/得跑…」= 规则陈述，不是验证记录。
3. **必须自证**：标题含 T1 但节内无实质证据 ⇒ 不算（只提及 ≠ 验证）。

## 四、落地方式（范围刻意收窄）

| 项 | 做法 |
| -- | -- |
| 生效范围 | **只对新卡**（ingest 落权威区时补 `evidence`）；**存量 616 张一律不动** |
| 不覆盖 | 卡已声明 `evidence` ⇒ 不覆盖（尊重作者显式取值） |
| `grade` | **完全不动**（含新卡的 grade 仍按 `DEFAULT_GRADE_BY_DIR` 保守补齐） |
| 校验 | `validate_card` 增 evidence 枚举校验；**可选字段**（缺失不报错 ⇒ 存量卡不集体变 invalid） |
| 检索行为 | **本轮不改**（分层仍按 `grade`）—— 先把信息落下来，改检索需另行评估 |

## 五、实测基线（存量 626 张按 v3 规则回放）

| 档 | 张数 | 占比 |
| -- | -- | -- |
| `t1` | 90 | 14% |
| `measured` | 46 | 7% |
| `none` | 490 | 78% |

⇒ **22% 的卡带证据**（此前 grade 轴无法表达这层信息：`task` 档里就有 27 张带 measured）。

## 六、局限与后续

1. **召回偏低**：v3 宁可漏不可错标 ⇒ 只抓「有结构标记」的验证记录；散文中口头描述的验证（无小节/无结果形态）会漏。
2. **存量未回填**：存量 626 张不带 `evidence`（查询时按 `none` 处理）⇒ 若要回填，须**逐条裁定**（不能批量推断，见 §一）。
3. **检索侧未用上**：`evidence` 目前只落盘可查；「用它改注入分层/摘要长度」需另开一轮评估（改检索行为影响面大）。
4. **配套护栏**：`tests/test_evidence_axis.py` 11 例（含「提及不算」「要求语气不算」「引用不算」「端到端入库自动补」「不覆盖显式声明」）。
