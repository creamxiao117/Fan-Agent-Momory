经验 → 方法论 → 技能 的 6 阶段闭环

阶段详解

6 阶段闭环

  • 实践 → 用户执行任务，产生经验
  • 沉淀 → 经验卡写入草稿区 (.sync/drafts/)
  • 提炼 → 模式识别 → 方法论/规则/蓝图
  • 萃取 → ⭐ 方法论 → Skill/MCP 工具
  • 淬炼 → T1 真实任务试用 → 验证通过
  • 反馈 → 有效技能反哺下一轮实践

挂点分类

A-E 挂点

  • A（发动机）：反哺复用路径——已验证技能自动推荐
  • E（发动机）：验证信号——T1 通过触发 active 转态
  • B（维护站）：回收——过期/失效卡归档
  • C（维护站）：去重——ingest 相似度判重
  • D（维护站）：养分——每日巡检补充缺失查询

关键转码

萃取（Stage 4）

  • 经验卡 → 方法论卡（methodology/）
  • 方法论卡 → SkillHub 技能（SKILL.md + skill.yaml）
  • 技能 → Skill 注册表（router.yaml）
  • Skill → Trae 技能系统（.trae/skills/）
  • 每一圈飞轮 = 一个可复用能力的诞生
