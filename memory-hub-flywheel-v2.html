记忆中枢 · 自驱成长飞轮 v2

从经验到技能的 6 阶段闭环飞轮

每个阶段产出 durable artifact → 写入中心记忆 → 下一轮放大。A/E 为发动机，B/C/D 为维护站。

A · 发动机

自动飞轮触发 & Skill 注册

auto_flywheel.py：扫描 .sync/drafts/ → 按平台 ingest → build-vectors → 写 flywheel-log.json

skill_create_from_card.py：中枢卡 → SKILL.md + skill.yaml + router.yaml 条目

skill_smoke_test.py：reference 技能验证 → promote active → 自动打 git tag

B · 维护站

分类器 & 路由同步

card_classifier.py：基于关键词对 experience 卡自动推荐 type（methodology/rule/blueprint）

router_sync.py：中枢 trae-tool-router.md ↔ SkillHub router.yaml 双向 diff

missing_query.py：消费 query.log → 识别 P0 未命中 / P1 低命中 → 补卡候选

E · 度量

运行日志 & 健康度

flywheel_runlog.py：记录每圈飞轮阶段 → 生成时间线回放 HTML

hub_health.py：飞轮转速 / 命中率 / reuse_count / 完整度评分

metrics_daily.py：每日卡片数/向量数/查询数/hit_rate → metrics.jsonl

可优化方向 · 基于当前飞轮架构

① 草稿自动触发
auto_flywheel 目前需手动调用或 cron。可接入 MCP 层：每次 hub_ingest_candidate 写草稿后自动触发一整圈飞轮。
② Skill 冒烟异步化
smoke_test 目前串行跑所有 reference 技能。可改为并行或分批，减少飞轮单圈耗时。
③ 分类器 ML 化
card_classifier 目前基于关键词匹配。可接入中枢向量检索做语义相似度分类，提升低置信度卡的准确率。
④ 反馈→实践自动回写
反馈阶段的 missing_query 候选需人工确认后 ingest。可增加"低风险 P1 自动补 tag"策略，人工只管 P0。
⑤ 版本语义化
skill 打 tag 用 v0.1.0 固定。可根据 reuse_count / 测试通过率自动升级补丁版本。
⑥ 飞轮自我监控
当前健康度是被动查询。可加：连续 N 圈飞轮无新产物时自动告警；命中率低于阈值时自动触发 missing_query。
⑦ Skill 能力画像
Skill 创建时只取卡前 500 字。可加能力标签（数据处理/代码生成/文档写作），便于后续智能路由。
⑧ 飞轮节奏自适应
固定每日 cron 可能与实际产出率不匹配。可改为"有草稿就跑、无草稿跳过"的事件驱动模式。
⑨ 跨平台经验迁移
sync 目前单向 pull。可加"技能已在 A 平台验证→自动推荐 B 平台试用"的迁移路径。
